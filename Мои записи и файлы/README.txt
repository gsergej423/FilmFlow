FilmFlow — версия с несколькими профилями

Откройте index.html.
На странице «Профиль» можно:
- создавать и переключать профили;
- хранить для каждого профиля отдельные просмотры, избранное, «смотреть позже» и плейлисты;
- копировать код профиля;
- импортировать код в другом браузере.

Важно: статический сайт не может автоматически синхронизировать разные браузеры без сервера.
Для переноса используйте кнопку «Копировать код профиля», а в другом браузере — «Импортировать код».

Папку media из исходного проекта нужно положить рядом с index.html.
