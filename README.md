# FilmFlow — Онлайн-кинотеатр (прототип)

FilmFlow — это прототип современного онлайн-кинотеатра, реализованный на чистом HTML, CSS и JavaScript (без фреймворков). Проект включает каталог фильмов и сериалов, систему управления контентом, кастомный видеоплеер, телепрограмму российских каналов, а также тематический раздел, посвящённый вселенной Гарри Поттера.

## ✨ Возможности

- 📚 **Каталог фильмов/сериалов**  
  Поиск, фильтрация по жанру, стране, возрасту, году и рейтингу.
- 🎬 **Карточки контента** с постерами, описанием, рейтингом.
- 📺 **Сериалы** — поддержка нескольких сезонов и эпизодов, сохранение прогресса просмотра.
- ▶️ **Кастомный видеоплеер**  
  - Управление воспроизведением, громкостью, скоростью.  
  - Полноэкранный режим.  
  - Горячие клавиши (пробел, стрелки, Esc).  
  - Сохранение позиции просмотра в `localStorage`.
- ❤️ **Избранное** и **«Смотреть позже»** — списки, синхронизированные с локальным хранилищем.
- 👤 **Профиль пользователя** с настраиваемым именем и статистикой.
- 📡 **Раздел «ТВ»**  
  - Сетка российских телеканалов с категориями.  
  - Расписание передач на сегодня и архив.  
  - Встроенные прямые эфиры (через Rutube/VK Видео).
- ⚡ **Раздел «Магия»** — все фильмы о Гарри Поттере в хронологическом порядке с уникальным оформлением.
- 💾 **Полное сохранение данных** в `localStorage` (избранное, прогресс, история, имя профиля).

## 🛠️ Технологии

- **HTML5** + семантическая разметка
- **CSS3** (переменные, гриды, флексбоксы, адаптивная вёрстка)
- **Vanilla JavaScript** (ES6+, IIFE-модуль)
- **localStorage** для хранения состояния
- **Rutube / VK Видео** — встраивание iframe для прямых эфиров
